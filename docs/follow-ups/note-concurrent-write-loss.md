# 노트 동시 저장 시 카드 유실

## 증상
탭 두 개에서 거의 동시에 질문을 제출하면, 나중에 쓴 요청이 먼저 쓴 요청의 카드를 덮어써 일부 카드가 `.data/note.json`에서 사라집니다. 화면에는 저장된 것처럼 표시됩니다.

## 근거
`lib/note.ts`의 `appendToNote`가 `readNote` → `mergeCards` → `writeFile`을 잠금 없이 수행합니다. 두 호출이 겹치면 각자 읽은 스냅샷 기준으로 병합해 마지막 쓰기만 남습니다.

## 상태
`code-review low`에서 지적됐고 재현은 시도하지 않았습니다. 주 경로(단일 사용자 순차 사용)는 깨지지 않고 `docs/specs/situated-paper-search/spec.md`의 수용 기준도 깨지지 않아 이번 범위에서 제외했습니다.

## 다음 단계
팀 4명 공유(현재 spec에서 유보한 지점)를 구현할 때 저장 계층을 함께 정합니다. 파일 잠금보다는 그 시점에 도입할 저장소에서 원자적 갱신으로 푸는 쪽이 자연스럽습니다.
